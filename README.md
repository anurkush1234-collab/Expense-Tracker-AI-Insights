# 💰 Expense Tracker AI Insights

A full-stack MERN (MongoDB, Express, React, Node.js) Expense Tracker application with AI-based insights, authentication, and interactive analytics dashboard.

🌐 Live Demo: https://frolicking-moonbeam-baa0b9.netlify.app  
🚀 Backend API: https://expense-tracker-ai-insights-2.onrender.com

---

## 📌 Features

### 🔐 Authentication
- User Signup & Login system
- JWT-based authentication
- Secure API access using tokens

---

### 💸 Expense Management
- Add income and expense transactions
- Edit and delete transactions
- Category-wise tracking (Food, Salary, Electronics, etc.)

---

### 📊 Dashboard Analytics
- Total Income calculation
- Total Expense calculation
- Remaining Balance display
- Real-time updates after every transaction

---

### 📈 Data Visualization
- Interactive Pie Chart using Recharts
- Income vs Expense comparison
- Clean and responsive UI charts

---

### 🤖 AI Insight System
- Smart spending insight message
- Alerts when expenses cross limits
- Basic financial behavior analysis

---

### 🌐 Full Stack Integration
- React frontend deployed on Netlify
- Node.js + Express backend deployed on Render
- MongoDB Atlas database integration
- Environment-based API configuration

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- Recharts
- CSS (Inline Styling)

**Backend:**
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- CORS

**Deployment:**
- Frontend: Netlify
- Backend: Render
- Database: MongoDB Atlas
